# RotP-HeyYa--Addon
A Minecraft addon project that adds Hey ya! inspired abilities to the Ripples of the Past mod.
Rotp: Hey ya! is an addon for Ripples of the Past that adds Hey ya! as a playable Stand

This add-on features a Stand from *JoJo's Bizarre Adventure* that will help you stay alert and find the determination you need.

The add-on also includes skins inspired by other popular franchises.

This add-on was created with the help of AI! (the code only)

Requirements:
Ripples of the Past
Minecraft Forge 1.16.5

Build
Same as the example addon: set main_mod_version in gradle.properties to a RotP snapshot, then ./gradlew build (JDK 8 toolchain).
